---

## ⚙️ System Tweaks

- **Disable fullscreen optimizations:** Right-click game .exe → Properties → Compatibility → Disable fullscreen optimizations.
- **Enable Hardware-accelerated GPU scheduling:** Windows Settings → System → Display → Graphics → Default graphics settings.
- **Set power plan to High Performance:** Control Panel → Power Options → High Performance.

---

## 📌 Why These Tools Work

- Free up RAM for smoother gameplay.
- Reduce input lag and system latency.
- Prioritize GPU and CPU resources for games.
